# 安全 G0 - 负压爬壁机器人

## 一、危险源清单
| 危险源 | 后果 | 预防措施 |
|---|---|---|
| 2S/3S 锂电池 | 过充、鼓包、起火 | 只在指定区域充电；发热/鼓包立即停机上报 |
| 涵道风机桨叶 | 高速飞出割伤 | 必须台架固定+护罩，禁止手持满转速 |
| N20 电机与轮 | 卷发、夹手 | 上电前清空手部区域，固定整机 |
| 正负极接反 | 烧电调、烧板 | 上电前核对 XT60 红正黑负 |
| 短路/线材裸露 | 冒烟、起火 | 上电前万用表测通断，绝缘包扎 |

## 二、上电前检查表（每次必走）
1. 电池极性核对（红正黑负）
2. 电调/驱动接线无松动
3. 共地确认（ESP32 与驱动、电调共地）
4. 风扇周围无杂物、护罩已装
5. 手部离开运动部件
6. 电源开关处于断开位
7. 串口/网页控制已连通
8. 失联停机逻辑已启用
9. 灭火器位置已知
10. 在场人员已知晓紧急停机方式

## 三、紧急停机顺序
1. 先断动力电（拔电池/关主电闸）
2. 再断控制电（USB/降压输出）
3. 报告组长，记录现象（时间、声响、气味、冒烟位置）
