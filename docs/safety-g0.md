## 一、五类高风险操作与红线

| 危险源 | 必须做到 | 禁止事项 |
|---|---|---|
| 锂电池与动力供电 | 查看额定参数；按批准场所与流程充放电；鼓包/异常热立即报告 | 宿舍充电、无人看守、盐水浸泡报废、私拆受损电池 |
| EDF高速风机 | 只在固定防护台架、隔离区、独立断电条件下做经批准的测试 | 无防护满转速、手持测试、靠近进气或旋转区 |
| 永磁体（本赛道不涉及） | 小尺寸封装试样、工装、护目镜 | 单手硬掰大型强磁、磁体自由碰撞 |
| 四足舵机/机械（本赛道不涉及） | 限角度限速、初次悬空测试 | 堵转继续供电、手放夹点 |
| 垂直爬壁 | 低高度固定台架、独立防坠、人员隔离，先做静态力学验证 | 未批准上墙、站在机器人下方、用软件停机代替防坠 |

## 二、上电前六步检查（每次上电必走）
- [ ] 1. 断电状态检查：线序、极性、机械干涉、螺丝、绝缘；不能只凭万用表蜂鸣档判断绝对安全
- [ ] 2. 电源检查：供电电压匹配、保护器件与限流设置、核对驱动器与电机额定值
- [ ] 3. 固定检查：车轮、风机、测试台架、防坠装置可靠固定
- [ ] 4. 软件检查：上电默认安全状态、速度/角度限幅、无线失联停车已在低风险条件下验证
- [ ] 5. 人员检查：操作人、观察人、授权人员（如需）清楚急停位置，旁人已离开危险区
- [ ] 6. 记录检查：实验编号、设备、目标、参数、异常停止条件已填写

## 三、异常处理顺序
发现异常热、冒烟、异响、振动、裂纹、下滑、通信失联或人员受伤：
1. 立即停机 / 独立断电
2. 撤离并隔离危险区
3. 联系现场授权人员，按学校应急流程处理
4. 保存事实记录
5. 经批准后才可重新实验

> 禁止：徒手触碰可能带电或受损的电池；未经训练自行灭火或拆解。
