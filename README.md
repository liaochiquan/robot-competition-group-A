## 📌 项目简介
本项目基于开源项目 BEETLE-ROBOT 复现一台负压吸附式爬壁机器人。机器人依靠负压吸附结构吸附在竖直壁面，配合行走机构实现壁面移动；主控使用ESP32，完成吸力控制、行走运动控制、传感器采集等功能，用于壁面检测、巡检类场景。

## ▶️ 演示方法
1. 硬件接线：按照 hardware 内接线图完成ESP32、真空泵、电机、传感器接线；
2. 烧录程序：将 firmware 内源码用Arduino IDE编译并烧录至ESP32；
3. 上电调试：检查负压吸附结构气密性，启动真空泵，测试机器人吸附、前进、转向功能；
4. 性能测试：在平整竖直墙面开展吸附可靠性、移动稳定性测试，测试数据存入 tests 和 data 目录。
