
# BEETLE-ROBOT 基线调研摘要
项目：负压吸附爬壁机器人复现项目
核对日期：2026-11-25

## 1. 原始来源链接
- 原型项目：BEETLE-ROBOT
- 参考教程平台：CircuitDigest https://circuitdigest.com/

## 2. 原版基线硬件清单
- 主控：ESP32
- 行走驱动：DRV8833，N20编码减速电机（6V）
- 负压吸附单元：无刷涵道电机+ESC电调
- 传感器：压差负压传感器、MPU6050姿态传感器
- 电源：2S 7.4V锂电池供电，DC-DC降压5V给控制部分

## 3. 许可说明
本项目为课程实训复现项目，基于BEETLE-ROBOT开源方案二次开发，遵循MIT开源协议。所有内容仅限学习、实训演示使用，不用于商业用途。

## 4. 调研结论
本方案依靠负压腔形成负压吸附在竖直壁面，ESP32统一完成负压闭环控制、行走电机控制、传感器采集。本组在此基础上做器件选型优化、布线优化。
