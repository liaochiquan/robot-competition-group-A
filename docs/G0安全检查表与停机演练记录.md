## 二、紧急停机桌面模拟演练记录
演练形式：桌面推演、手势模拟，不上电
演练人员：廖炽权、赵烨环、刘梓锐
演练时间：2026‑11‑25

演练流程：
1. 模拟故障场景：腔体负压异常，发生故障风险
2. 软件保护推演：ESP32检测异常，程序逻辑关闭负压风机、行走电机PWM输出。
3. 硬件急停推演：操作人员动作模拟按下整机电源总开关，切断整机供电。
4. 独立断电推演：模拟拔出XT30电池插头，彻底断开整机能源输入。

演练结论：
小组全部成员熟悉危险源、紧急停机处置流程；软硬件两级停机方案完整，满足G0安全准入要求。
